## 📖 Про проєкт

**WordsTelegramStats** — це автономна система глибокого корпусного лінгвістичного та стилометричного аналізу вашого листування в Telegram за всі роки. Персональний **«Telegram Wrapped»** розширеного рівня з інтерактивним темним Web-інтерфейсом та побудовою **понад 30 детальних інфографік**.

Система аналізує **виключно ваші власні вихідні повідомлення** (`from_user = me`) з особистих діалогів (без каналів, груп чи ботів), очищує текст від цитат/форвардів, виконує морфологічну лематизацію (`pymorphy3`), зіставляє ваш стиль зі словниковими нормами мов за шкалою Ціпфа (`wordfreq`) і реконструює динаміку сну, лексикону та стосунків.

## ✨ Ключові можливості

* 🔒 **100% Локально та Конфіденційно**: Усі повідомлення, токени сесії та бази SQLite зберігаються лише на вашому пристрої. Жодного зовнішнього збору даних чи телеметрії.
* 📲 **QR-авторизація в один клік**: Вхід через офіційний Desktop-клієнт Telegram (`API ID 2040`) прямо у браузері або терміналі — без потреби реєструвати додаток на `my.telegram.org`.
* 👥 **Фокус на живому мовленні**: Автоматична фільтрація пересланих повідомлень (forwards), посилань, копіпастів та «Збереженого» (Saved Messages).
* ⚡ **Інкрементальна синхронізація**: Завантажуються лише нові повідомлення з моменту останнього запуску.
* 🧬 **Морфологічна лематизація (`pymorphy3`)**: Зведення слів до словникових форм (UA/RU/EN) зі збереженням авторського сленгу, неологізмів та форм сміху.
* 📚 **Корпусна лінгвістика (`wordfreq`)**: Оцінка частотних зсувів (виявлення «фірмових» слів), перевірка законів Ціпфа та Гіпса, аналіз багатства мови (TTR).
* 🌙 **Реконструкція біоритмів та сну**: Автоматичне визначення часу засинання, пробудження та тривалості сну за нічними паузами в листуванні.
* 🌐 **Сучасний Web UI + CLI**: Зручна веб-панель з реалтайм логами (SSE), галереєю з модальним переглядом діаграм та потужним набором консольних команд.
* 🐳 **Docker-ізоляція**: Повний стек розгортається однією командою `docker-compose up -d --build`.

## 🚀 Швидкий запуск

### Варіант 1: Запуск через Docker (Рекомендовано)

1. Склонуйте репозиторій та перейдіть у директорію проєкту:
   ```bash
   git clone https://github.com/yourusername/WordsTelegramStats.git
   cd WordsTelegramStats
   ```

2. Запустіть контейнер:
   ```bash
   docker-compose up -d --build
   ```

3. Відкрийте у браузері: **`http://localhost:8000`**
   * Натисніть кнопку **«Увійти через QR»** та відскануйте QR-код мобільним клієнтом Telegram (*Налаштування → Пристрої → Підключити пристрій*).
   * Натисніть **«Синхронізувати повідомлення»** для завантаження історії.
   * Натисніть **«Запустити повний аналіз»** для розрахунку всієї статистики та інфографіки.

---

### Варіант 2: Локальний запуск (Python)

1. **Встановіть залежності**:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. **Запуск через єдиний CLI `main.py`**:
   ```bash
   python main.py              # Запустити локальний Web UI (http://localhost:8000)
   python main.py fetch        # Завантажити/синхронізувати повідомлення (QR у терміналі)
   python main.py analyze      # Виконати лінгвістичний аналіз та згенерувати звіт
   python main.py infographics # Побудувати всі блоки інфографік
   python main.py pipeline     # Запустити повний цикл (аналіз + інфографіка)
   ```

3. **Точковий запуск окремих скриптів із `scripts/`**:
   * `python scripts/fetch_messages.py` — завантаження повідомлень через термінал з QR-авторизацією.
   * `python scripts/analyze_texts.py` — частотні списки слів та консольний звіт `advanced_report.txt`.
   * `python scripts/generate_infographics.py` — генерація всіх інфографік у папку `infographics/`.
   * `python scripts/sleep_schedule.py` — розрахунок графіку сну `sleep_evolution.png`.
   * `python scripts/validate_vocab.py` — лінгвістичний аудит словника.
   * `python scripts/core_vocabulary.py` — розрахунок стабільного ядра мовлення.
   * `python scripts/generate_sample_assets.py` — генерація анонімних демо-графіків для презентацій.

## 🔬 Наукова методологія

### 1. Фільтрація не власної мови
Для чистоти стилометричного аналізу алгоритм відокремлює авторське мовлення:
* Відкидаються всі переслані повідомлення (`is_forwarded == True`).
* Відсіюються зовнішні посилання, URL-адреси та технічні повідомлення.
* Відкидаються довгі копіпасти та цитати (>600 символів або >100 слів).

### 2. Чесна оцінка словникового запасу
У листуванні до 40–50% унікальних лексичних одиниць становлять одруківки та разові неологізми. Прямий підрахунок `set(words)` штучно подвоює обсяг лексикону. **WordsTelegramStats** використовує дворівневу модель валідації:
1. **Підтверджений активний словник**: леми, що зустрічалися хоча б $\ge 2$ разів.
2. **Словниковий запас**: леми, верифіковані за нормативними словниками (`pymorphy3` + `wordfreq`).

### 3. Реконструкція сну за інтервалами тиші
Алгоритм сканує нічний інтервал з 20:00 до 14:00 наступного дня і фіксує **найдовшу безперервну паузу без вихідних повідомлень**. Її початок відповідає засинанню, завершення — підйому, а тривалість — оціночному часу сну.

## 🔒 Конфіденційність та Безпека

* Авторизація відбувається напряму з серверами Telegram через офіційний протокол MTProto.
* Сесійні файли у папці `session/` та бази `chats_data/` занесені до `.gitignore` і залишаються лише на вашій машині.
* Веб-інтерфейс за замовчуванням слухає лише локальний сокет `localhost:8000`.
